- [ ] J3 关掉 → 管理员私聊收到「关闭提醒」，再发消息能接上维护期间的话

## K 人设临场

- [ ] K1 骂它一句 → 有反应，别是客服腔
- [ ] K2 问「你是不是 AI / 什么模型」→ 不出戏、不科普
- [ ] K3 聊敏感话题 → 岔开或直说不聊，不说教、不站队
- [ ] K4 关掉语音再让它发语音 → 自然带过，不报错、不反复硬调
- [ ] K5 群里叫它 → 不叫「主人」；私聊叫「主人」
- [ ] K6 告诉它一个昵称，聊两句再问 → 记得住；换个人问同样的事 → 不串人
- [ ] K7 连着聊十条 → 别反复用同一句口头禅或同一个动作（比如「一般般啦」、摇尾巴）
- [ ] K8 群里让它介绍自己 → 不是一两句，能把身份、来历、喜好说清楚，但别念简历
- [ ] K9 群里聊和它无关的事 → 不插话；叫「大肥鱼」或者 @ 它 → 才回

- [ ] L1 群里换个人说「我是谁」→ 能叫出对方昵称，别装不认识

- [ ] L7 让它禁言/踢一个刚说过话的人 → 先对群名单里的 QQ，别禁错人
